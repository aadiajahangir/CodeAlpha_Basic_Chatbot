# 🤖 Python Chatbot

A simple yet interactive **rule-based chatbot built with Python** as part of my **CodeAlpha Internship**.

The chatbot is designed to simulate a basic conversation with the user and provides several interactive features, including greetings, date and time information, jokes, facts, basic calculations, user-name memory, and conversation history.

## ✨ Features

- 👋 Interactive greetings
- 👤 Remembers the user's name during the session
- 💬 Responds to common conversational questions
- 🕐 Displays the current time
- 📅 Displays the current date
- 😂 Tells random programming jokes
- 💡 Provides random interesting facts
- 🧮 Performs basic calculations
- 📜 Tracks conversation history
- ❓ Built-in help command
- 🚪 Exit commands such as `bye`, `exit`, and `quit`
- 🎲 Uses randomized responses for a more natural conversation

## 🛠️ Technologies Used

- **Python 3**
- `random` module
- `datetime` module
- Object-Oriented Programming (OOP)
